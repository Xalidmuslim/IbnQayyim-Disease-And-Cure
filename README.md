# Болезнь и исцеление · Android v45

Офлайн-приложение для чтения книги Ибн аль-Каййима «Болезнь и исцеление».

## Состав
- **114 глав** и полный текст русского редакционного архива v44;
- **502 вопроса** викторины с подтверждениями и справочник из **213 примечаний**;
- существующий дизайн и нижняя навигация сохранены через Kotlin WebView;
- **аудиоверсии нет** и в APK не добавляется.

## Сборка APK
Откройте вкладку **Actions** → **Android APK v44** → последний успешный запуск → **Artifacts** → `IbnKayim-v44-Android-debug-apk`. В ZIP будет `app-debug.apk`. При необходимости запустите workflow вручную через **Run workflow**.

### Технические особенности

Это Android-оболочка (Kotlin/Android WebView) над исходной HTML-читалкой, а не переписанное на Compose приложение. Работает без INTERNET permission, с локальным хранением прогресса и настроек WebView. Привязка функций к жестам/кнопке Back и дизайн на физическом Android-устройстве требуют самостоятельной приёмки.

Оригинальный HTML редакции v44 хранится в `app/src/main/assets/index.html`; его SHA-256 контролируется тестами. До выпуска в магазин требуются проверка авторских прав конкретного перевода, смысловая сверка оригинала, восстановление отсутствующих в архиве шрифтов и изображений и реальное устройство.

## Локальная сборка

JDK 17, Android SDK 35, Gradle 8.10.2:

```sh
python3 -m unittest discover -s tests -v
gradle :app:assembleDebug --no-daemon
```

Итог: `app/build/outputs/apk/debug/app-debug.apk`.

## Восстановление визуального оформления v45

- Все 23 бинарных ресурса (шрифты, книжные фоны, изображения и лицензии) восстановлены побайтно из проверенного комплекта 1.19.
- Встроенный HTML редакции v44 **не изменён** (проверяется SHA-256). Размер текста WebView зафиксирован на 100%; сохранён `width=device-width` без обзорного уменьшения.
- Тест `tests/test_visual_resources.py` проверяет контрольные суммы всех исходных ресурсов и настройки WebView.
- **Внимание:** GitHub Actions использует отладочную подпись; новая сборка может быть несовместима с подписью установленного v44 APK. Не удаляйте прежнее приложение без сохранения прогресса.
- Для подтверждения точного визуального совпадения требуется сравнение двух APK на одном Android-устройстве; браузерная проверка не равнозначна проверке WebView на телефоне.

- Оригинальная иконка запуска приложения восстановлена из v1.19 и назначена в AndroidManifest.

**Безопасная установка:** тестовая debug-сборка v45 использует package `com.xalidmuslim.diseaseandcure.preview45` и устанавливается рядом с v44 без удаления прежней программы. Прогресс между двумя пакетами не переносится автоматически. Не удаляйте старую программу без резервной копии.

## v46 — управление назад и типографика

- Android 13–16: системный Back (свайп от края) обрабатывается через OnBackInvokedDispatcher. Android 8–12 сохраняет прежний onBackPressed(); оба вызывают window.__androidBack и навигацию в существующем HTML.
- Оглавление и карточки разделов на главном экране используют компактный Roboto Condensed (Reader Navigation), 14 px / 1.30. Шрифты книжного текста и иконки не затронуты.
- Размер текста в читалке по умолчанию уже был 17 px, интервал — 1.40; пользовательские настройки сохраняются. HTML с 114 главами, 502 вопросами, 213 примечаниями не изменён.
- Новый отладочный пакет .preview46 устанавливается отдельно от v44 и v45: закладки старой версии остаются на месте, но автоматически не копируются.
- APK появляется после успешного запуска Android APK v46 → Artifacts.
