# Болезнь и исцеление · Android v44

Офлайн-приложение для чтения книги Ибн аль-Каййима «Болезнь и исцеление».

## Состав
- **114 глав** и полный текст русского редакционного архива v44;
- **502 вопроса** викторины с подтверждениями и справочник из **213 примечаний**;
- существующий дизайн и нижняя навигация сохранены через Kotlin WebView;
- **аудиоверсии нет** и в APK не добавляется.

## Сборка APK
Откройте вкладку **Actions** → **Android APK v44** → последний успешный запуск → **Artifacts** → `IbnKayim-v44-Android-debug-apk`. В ZIP будет `app-debug.apk`. При необходимости запустите workflow вручную через **Run workflow**.

### Технические особенности

Это Android-оболочка (Kotlin/Android WebView) над исходной HTML-читалкой, а не переписанное на Compose приложение. Работает без INTERNET permission, с локальным хранением прогресса и настроек WebView. Привязка функций к жестам/кнопке Back и дизайн на физическом Android-устройстве требуют самостоятельной приёмки.

Оригинальный HTML редакции v44 хранится в `app/src/main/assets/index.html`; его SHA-256 контролируется тестами. До выпуска в магазин требуются проверка авторских прав конкретного перевода, смысловая сверка оригинала, восстановление отсутствующих в архиве шрифтов и изображений и реальное устройство.

## Локальная сборка

JDK 17, Android SDK 35, Gradle 8.10.2:

```sh
python3 -m unittest discover -s tests -v
gradle :app:assembleDebug --no-daemon
```

Итог: `app/build/outputs/apk/debug/app-debug.apk`.
